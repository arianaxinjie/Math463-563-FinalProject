Extra Grid Search and Line Search

The experimental search utilities now live under extra_grid_search/. This keeps the core solver package cleaner while preserving compatibility wrappers under the old module paths.

Run Grid Search

python -m extra_grid_search.grid_search

Stage-2 search-space JSON files are stored in extra_grid_search/configs/, and related reports live in extra_grid_search/docs/.

Monitor Progress

python -m extra_grid_search.grid_search_status output/grid_search/cameraman_gaussian_sp
python -m extra_grid_search.grid_search_dashboard --output-dir output/grid_search/full_run_l1

Run Line Search

python -m extra_grid_search.line_search

This script is an offline parameter sweep for Algorithm 1's tprimaldr, rather than an in-iteration backtracking rule.
